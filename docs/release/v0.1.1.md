# Rpy v0.1.1

Release de manutenção preparado a partir do trabalho acumulado após o histórico `v0.1.0`.

## Escopo

- preserva a arquitetura FastAPI + PostgreSQL 16 + pgvector;
- consolida os guardrails de release, CI, segurança e deployment;
- mantém o fluxo Judit assíncrono com diagnóstico seguro antes de chamadas potencialmente pagas;
- adiciona suporte de captura/replay para evidência de integração de provider;
- mantém DataJud como enriquecimento opcional com gate explícito de uso autorizado;
- reforça imagem de produção imutável, SBOM/provenance, attestation e validação de runtime;
- protege a branch `main` com PR obrigatório, checks obrigatórios e bloqueio de delete/force-push.

## Provider acceptance

Provider acceptance continua ambiente-específica e separada da qualificação offline do artefato. Judit ainda exige resolução do diagnóstico HTTP 400 antes de qualquer novo POST potencialmente pago. O DataJud-only deve ser executado explicitamente em modo próprio para constituir evidência live.

## Activation boundaries

LGPD/governança, autorização de provider, produção real, ingress/TLS, armazenamento externo de backup, RPO/RTO e demais evidências ambiente-específicas não são inferidas desta release de software.

Consulte `docs/release/provider-acceptance.md`, `docs/release/next-release.md` e `docs/deployment/`.
